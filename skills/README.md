# Legal Agent Task Skills

Use [legal-agent-data-workflow](legal-agent-data-workflow/SKILL.md) as the end-to-end workflow. Invoke a specialist skill for an individual stage:

1. [Taxonomy design](legal-taxonomy-design/SKILL.md) — legal domain, operation, scenario, evidence pattern, and deliverable coverage.
2. [Source research](legal-source-research/SKILL.md) — primary-source collection, provenance, and material roles.
3. [Evidence graph](legal-evidence-graph/SKILL.md) — source spans, propositions, knowledge points, and dependency links.
4. [Task authoring](legal-task-authoring/SKILL.md) — attorney-style query and solver-visible workspace.
5. [Rubric engineering](legal-rubric-engineering/SKILL.md) — atomic, evidence-backed criteria.
6. [Hinted validation](legal-hinted-validation/SKILL.md) — solvability, judging, controls, and revision loop.
7. [No-hint evaluation](legal-nohint-evaluation/SKILL.md) — frozen target-model evaluation and metrics.
8. [Release audit](legal-dataset-release-audit/SKILL.md) — provenance, leakage, score integrity, and export checks.

Shared detailed process: [workflow reference](legal-agent-data-workflow/references/workflow.md). Source design report: [REPORT.html](../REPORT.html).
