# Legal Task Authoring

Write a work request that sounds like a lawyer assigning a real task to a colleague. The query and workspace must support the requested deliverable without revealing the rubric or answer.

## Authoring steps

1. Confirm the taxonomy card, client context, jurisdiction, law-as-of date, and deliverable.
2. Draft a concise query, ordinarily under 50 words. State the action, subject, relevant time, and requested output. Avoid classroom phrasing and enumerated rubric items.
3. Keep decisive facts in the attached source workspace. Do not require facts absent from those materials.
4. Include useful, corroborating, hard-negative, context, or irrelevant material only when its role is realistic and documented.
5. Name the deliverable and format; make the work product useful to a legal team or client.
6. Check that the query is novel relative to LAB task text and that no LAB source document is included.

Difficulty should arise from relationships such as authority, time, parties, conditions, and cross-document status. Return `task.json`, query text, deliverable specification, and workspace document list. See [the shared workflow reference](../legal-agent-data-workflow/references/workflow.md).
